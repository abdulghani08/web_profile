## Selection rubric

Score each candidate 0–3 for:
1. Evidence available
2. Relevance to target roles
3. Clarity of personal contribution
4. Technical depth that can safely be shared
5. Outcome or real-world use
6. Visual/demo availability and permission

Select featured case studies only after owner review. A high user count alone does not prove individual engineering impact.
