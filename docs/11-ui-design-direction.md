# UI and Design Direction

## Approved direction

Modern, professional, engineering-first, distinct, readable, and restrained. Design should communicate technical credibility rather than imitate a generic agency landing page.

## Visual principles

- Strong typographic hierarchy and generous but purposeful spacing.
- Clear content grid and consistent alignment.
- Restrained color palette with sufficient contrast.
- Visual emphasis on real project evidence, diagrams/screenshots only when permitted.
- Subtle motion only when it improves feedback or orientation.
- Consistent interaction states: default, hover, focus, active, disabled, loading, error where applicable.
- Avoid gratuitous glass effects, 3D scenes, excessive gradients, cursor gimmicks, and large animation payloads unless a clear user benefit is demonstrated.

## Design system deliverables (Phase 4)

- Color tokens and semantic roles
- Typography scale and font loading strategy
- Spacing, container, and breakpoint rules
- Buttons, links, cards, tags, navigation, language switcher
- Project-card and case-study media patterns
- Focus, hover, active, and reduced-motion states
- Responsive behavior rules
- Accessibility review notes

## Open decisions

Exact colors, fonts, logo/monogram, imagery, icon library, animation approach, and breakpoint values are **PENDING DESIGN**. They must be justified through design exploration and owner approval, not assumed by the implementation agent.
