# SEO and Metadata Requirements

## Requirements

- Unique, descriptive page title and meta description for every indexable page and language.
- Correct canonical URL strategy once domain and routing are known.
- Appropriate language metadata and localized alternate links where supported by the chosen architecture.
- Open Graph and social preview metadata for important pages.
- Semantic headings and crawlable links.
- Descriptive URLs/slugs that remain stable where practical.
- Meaningful alt text for informative images.
- XML sitemap and robots directives if supported/appropriate for the chosen stack.
- No accidental `noindex` on production pages.
- Verify page titles, descriptions, canonical behavior, language alternates, and social cards after deployment.

## Content constraints

- Use natural language; avoid keyword stuffing.
- Do not create fake client/project pages just for search traffic.
- Do not publish unverified claims or private project details.
- Do not claim search ranking outcomes as guaranteed.
